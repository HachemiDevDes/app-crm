# UI Design Guidelines

When tasked with designing new UI components, building pages, or making visual adjustments to the application, you **MUST ALWAYS** read and follow the instructions in the `antigravity-design-expert` skill. 

Do not rely on standard web design defaults or external UI frameworks unless explicitly told to. You must strictly adhere to the project's established design DNA (glassmorphism, spatial UI, specific typography like Space Grotesk/Changa, and the precise color palettes) detailed within that expert skill.
